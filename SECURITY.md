# Security Policy

## Supported Versions

We actively maintain and support the following versions of macOS FaceUnlock with security updates:

| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: Yes |
| < 1.0.0 | :x: No |

---

## Reporting a Vulnerability

Because this platform integrates directly into the macOS PAM authentication boundary and runs under root contexts during active logins, security bugs represent a high risk. If you find a security vulnerability, please do not open a public issue.

### Submission Process
1. Send an email to **hariom24229@iiitd.ac.in** describing the vulnerability.
2. Include a proof-of-concept (PoC) script, steps to trigger the bug, and the estimated impact.
3. We will acknowledge receipt of your report within 48 hours and work with you to triage and patch the vulnerability.

Please keep details confidential until we have published a security release to protect other users.
